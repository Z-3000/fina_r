# 세금 계산 로직 업데이트 (2024/2025 적용)

- 작업 일자: 2025-11-25 (로컬 적용 기준)
- 파일: `src/services/taxCalculator.js`
- 목적: 국세청 공시 기준에 맞춰 누진/한도/경감 규칙을 세분화

## 현재 구현 요약
- 도움되는 부분: 근로·사업자 소득세 구간, 세액공제, 간이과세 경감(50%, 최대 100만) 등 핵심 규칙을 반영해 “얼마나 낼지/줄일지” 감 잡기 좋음.
- 제한/주의: 의료·교육비 특례(장애인·65세 이상·3자녀·분리공제 등)와 인별 한도, 보험료 특례는 미반영(docs/tax-calculation-updates.md 세부 항목 참조). 사업자 쪽 업종별 부가가치율/간이과세 전환 구간, 특별세액감면, 성실신고 확인비용 등 세부 감면도 없음. 연도 선택이 없어 고시 변경 시 수동 업데이트 필요, 입력 검증이 단순해 잘못된 값이 들어가면 결과 왜곡 가능.
- 추천 보완:
  1. 화면에 “예상치·교육용” 라벨과 짧은 안내로 과신 방지.
  2. 의료/교육/기부를 항목·인별 입력 + 특례 토글(장애인·65세 이상·3자녀 등) 추가.
  3. 업종별 부가가치율/경비율 입력과 간이과세 판정용 직전연도 공급가액(8천만·1.4억 등) 필드로 경고/플래그 표시.
  4. 세율·공제율을 연도별 JSON으로 분리해 연도 선택 + 자동 업데이트 경로 확보.
  5. 결과 카드에 “국세청 홈택스 신고 전 확인 필요” 문구/링크 노출.

## 수정 요약
- 근로소득세액공제: 산출세액 55% 한도 66만 + 120만 초과분 30% 추가, 총 한도 74만으로 계산.
- 연금저축/IRP 세액공제율: 총급여 5,500만 이하 16.5% / 5,500만~1.2억 15% / 1.2억 초과 13.2% 3단계 반영.
- 기부금 세액공제: 법정/지정/종교 1천만원까지 15%, 초과분 30% + 소득 한도 적용; 정치자금 10만까지 100%, 10만~3천만 15%, 초과 25%로 구간화.
- 간이과세자 부가세: 매출×업종부가가치율×10%에서 매입세액 50% 공제 후, 납부세액 50% 경감(최대 100만) 적용 및 매출 8천만 초과 여부 플래그 추가.

## 참고/제한
- 의료·교육비 특례: 현재 입력이 단일 합산액이라 장애인·65세 이상·3자녀·분리공제 등 인별 특례와 한도를 반영하지 못함. 난임 플래그 외 특례는 추가 입력/필드 설계가 필요.
- 보험료 특례: 건강/고용/연금 외 별도 한도나 특례(보장성보험 100만원 한도 등)는 미반영.
- 기부금: 소득 기준 상한만 적용하며, 종교/지정 구분과 인별 한도는 전달 필드에 의존.
- 사업자 세부 규정: 업종별 부가가치율 테이블, 간이과세 전환/배제 구간(8천만·1.4억 등), 특별세액감면, 성실신고 확인비용, 농어촌특별세 등 추가 공제/감면은 미적용.
- 실제 신고 시기는 연도별 해석 차이가 있을 수 있으므로 최신 국세청 고시와 비교 검증 권장.
