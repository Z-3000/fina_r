## 1. 프로그램 소개

### FINA_R이란?

**FINA_R**은 **개인 및 소상공인을 위한 스마트 세금 관리 앱**입니다.

쉽게 말해서:
- 내가 쓴 돈을 기록하고
- 예산을 세우고
- 세금을 미리 계산해보고
- 연말정산 때 얼마를 환급받을 수 있는지 알려주는 앱

### 이 앱이 해결하는 문제

| 기존 문제 | FINA_R의 해결책 |
|-----------|-----------------|
| 영수증 정리가 귀찮음 | 사진 찍으면 자동으로 내용 인식 |
| 이번 달 얼마 썼는지 모름 | 카테고리별로 자동 정리 |
| 예산 초과하는 줄 모름 | 예산 대비 사용량 한눈에 표시 |
| 세금 계산이 어려움 | 정보 입력하면 자동 계산 |
| 연말정산 복잡함 | 시뮬레이터로 예상 환급액 확인 |

## 3. 기능별 상세 설명

### 3.1 로그인/회원가입 🔐

**무엇을 하는 기능인가요?**
- 앱에 로그인해서 내 정보를 안전하게 저장

**어떻게 구현했나요?**

| 방식 | 설명 | 구현 상태 |
|------|------|:---------:|
| 이메일 로그인 | 이메일과 비밀번호로 가입/로그인 | ✅ 완료 |
| 카카오 로그인 | 카카오 계정으로 간편 로그인 | ✅ 완료 |

**사용한 서비스:**
- **Supabase Auth** (무료 서비스)
  - Supabase라는 회사에서 제공하는 로그인 시스템
  - 비밀번호 암호화, 이메일 인증 등을 알아서 처리해줌
  - 카카오 로그인도 연동 가능

### 3.2 영수증 등록 📷

**무엇을 하는 기능인가요?**
- 내가 쓴 돈을 기록
- 영수증 사진을 찍으면 자동으로 금액, 날짜, 가게 이름을 읽어옴

**어떻게 구현했나요?**

| 방식 | 설명 | 구현 상태 |
|------|------|:---------:|
| 수동 입력 | 직접 날짜, 금액, 카테고리 입력 | ✅ 완료 |
| OCR 인식 | 영수증 사진에서 자동으로 정보 추출 | ✅ 완료 |

**OCR이란?**
- **O**ptical **C**haracter **R**ecognition의 약자
- 쉽게 말해: **"사진 속 글자를 읽어주는 기술"**
- 영수증 사진을 올리면 → 글자를 인식해서 → 금액, 날짜, 가게 이름을 자동으로 채워줌

**사용한 라이브러리:**
- **Tesseract.js** (무료 오픈소스 라이브러리)
  - Google에서 만든 OCR 엔진의 웹 버전
  - 한국어 + 영어 인식 가능 (`kor+eng` 모드)
  - API 키 불필요 - 사용자 브라우저에서 직접 처리
  - 이전에는 Naver CLOVA OCR을 사용했으나, 안정성 문제로 Tesseract.js로 전환 (v3.1)

**카테고리 자동 분류 예시:**

```
"스타벅스" → 식비
"GS25" → 편의점
"SK에너지" → 교통
"CGV" → 문화/여가
"올리브영" → 생활용품
```

### 3.4.1 세금 건강 점수 (Tax Health Score™) 🆕 v3.3

**무엇을 하는 기능인가요?**
- 내 세금 관리 상태를 0~100점으로 평가
- 점수가 높을수록 세금 관리를 잘하고 있다는 의미

**세부 점수 4가지** (캐시노트 방식 참고)

| 점수 | 무엇을 측정하나요? | 어떻게 계산하나요? |
|------|-------------------|-------------------|
| **세금 리스크** | 세무조사 위험도 | 증빙 누락, 한도 초과, 업종 평균 대비 이상치 체크 |
| **증빙 완성도** | 서류 준비 상태 | 공제 금액 50만원당 증빙 1개 필요 (국세청 권장) |
| **환급 가능성** | 연말정산 환급 예상 | 기납부세액 vs 예상결정세액 비교 |
| **절세 여력** | 추가 절세 가능성 | 아직 사용하지 않은 공제 한도 비율 |

**점수 산출 방식 (규칙 기반)**

```
1. 세금 리스크: 100점에서 시작, 문제가 있으면 감점
   - 증빙 부족: -10점씩 (최대 -30)
   - 한도 초과: -10점씩 (최대 -20)
   - 업종 평균 이탈: 최대 -15
   - 마감일 임박: -5~-10

2. 증빙 완성도: 업로드 비율 × 80 + 보너스
   - 필요 서류 = 금액 ÷ 50만원
   - 예: 의료비 150만원 → 최소 3개 영수증 필요

3. 환급 가능성: 예상 환급액 기준
   - 환급 예상되면 높은 점수
   - 추가 납부 예상되면 낮은 점수

4. 절세 여력: 남은 공제 한도 비율
   - 아직 쓸 수 있는 공제가 많으면 높은 점수
   - 한도를 다 채웠으면 낮은 점수
```

**왜 이렇게 바꿨나요?**

| 이전 방식 | 새 방식 |
|----------|---------|
| 전체 점수에 상수(+7, -13 등)를 더함 | 실제 데이터 기반으로 계산 |
| 사용자가 납득하기 어려움 | 왜 이 점수인지 설명 가능 |
| 모든 사용자에게 같은 패턴 | 개인 상황에 맞춤 |

### 3.5 세금 계산기 🧮

**무엇을 하는 기능인가요?**
- 내 소득과 공제 정보를 입력하면 예상 세금을 계산

**계산할 수 있는 것들:**

| 종류 | 대상 | 설명 |
|------|------|------|
| 근로소득세 | 직장인 | 월급에서 떼는 세금 |
| 연말정산 | 직장인 | 1년 치 세금 정산 (환급/추가납부) |
| 종합소득세 | 사업자/프리랜서 | 사업 수입에 대한 세금 |
| 부가가치세 | 사업자 | 물건 팔 때 붙는 세금 (10%) |

**이건 진짜 계산인가요, 가짜인가요?**
- **진짜 계산**입니다!
- 2024년 기준 한국 세율표를 적용
- 실제 국세청 계산 방식과 동일

**적용된 세율표 (2024년 기준):**

| 과세표준 | 세율 |
|----------|------|
| 1,400만원 이하 | 6% |
| 5,000만원 이하 | 15% |
| 8,800만원 이하 | 24% |
| 1.5억원 이하 | 35% |
| 3억원 이하 | 38% |
| 5억원 이하 | 40% |
| 10억원 이하 | 42% |
| 10억원 초과 | 45% |

### 3.6 연말정산 시뮬레이터 📋

**무엇을 하는 기능인가요?**
- 내 정보를 입력하면 연말정산 예상 결과를 미리 보여줌
- "얼마를 환급받을 수 있을까?" 또는 "추가로 내야 할까?"

**입력하는 정보:**
- 연간 총급여
- 부양가족 수 (부모님, 자녀 등)
- 배우자 유무
- 의료비 지출
- 교육비 지출
- 연금저축 납입액
- IRP 납입액
- 기부금

**결과로 보여주는 것:**
- 산출세액 (세금 원래 금액)
- 공제 금액 (깎아주는 금액)
- 결정세액 (실제 내야 할 세금)
- 실효세율 (실제 세금 비율)
- 예상 환급액 또는 추가 납부액

### 3.9 PDF/Excel 내보내기 📄

**무엇을 하는 기능인가요?**
- 내 지출 내역이나 세금 계산 결과를 파일로 저장

**내보낼 수 있는 것:**

| 종류 | 형식 | 내용 |
|------|------|------|
| 월별 지출 리포트 | PDF | 이번 달 지출 요약 + 상세 내역 |
| 연말정산 리포트 | PDF | 세금 계산 결과 |
| 세금 건강 리포트 | PDF | 공제 활용도 분석 |
| 거래 내역 | Excel | 모든 영수증 데이터 |
| 예산 현황 | Excel | 카테고리별 예산 vs 실제 |
| 종합 데이터 | Excel | 모든 데이터 통합 |

**사용한 라이브러리:**
- **jsPDF** - PDF 파일 생성 (영문 출력으로 폰트 이슈 해결)
- **jspdf-autotable** - PDF에 표(테이블) 추가
- **xlsx (SheetJS)** - Excel 파일 생성
- **file-saver** - 파일 다운로드 처리

**v3.1 개선사항:**
- PDF: @react-pdf/renderer 시도 후 폰트 로딩 문제로 jsPDF로 롤백
- Excel: taxResult, deductionTracker 등 null 참조 오류 수정
- 파일명: exportService.js → exportService.jsx (JSX 구문 지원)

실제 2024년 한국 통계를 참고하여 현실적인 금액으로 수정했습니다.

## 5. 데이터베이스 테이블 설명

### Supabase란?

- **한 마디로:** 무료로 사용할 수 있는 클라우드 데이터베이스 서비스
- **비유:** Google Drive가 파일을 저장하듯이, Supabase는 앱 데이터를 저장
- **장점:**
  - 무료 요금제로 충분히 사용 가능
  - 로그인 기능 기본 제공
  - 보안 설정 쉬움

### 테이블이란?

- **엑셀 시트**처럼 데이터를 행(Row)과 열(Column)로 저장하는 곳
- 예: `receipts` 테이블 = 영수증 정보 저장하는 엑셀 시트

## 8. 자주 묻는 질문

### Q1. 내 데이터는 어디에 저장되나요?

**A:** Supabase 클라우드 서버에 안전하게 저장됩니다.
- 서버 위치: 한국 또는 아시아 리전
- 암호화: 전송 중, 저장 중 모두 암호화
- 접근 권한: 본인 데이터만 볼 수 있음 (RLS 정책 적용)

### Q2. 세금 계산이 정확한가요?

**A:** 2024년 기준 한국 세법을 적용했습니다.
- 소득세율표: 국세청 기준 동일
- 공제 한도: 실제 법정 한도 적용
- 단, 개인 상황에 따라 실제 세금과 차이가 있을 수 있음
- **참고용**으로 사용하시고, 정확한 계산은 세무사 상담 권장

### Q3. OCR 인식률은 어느 정도인가요?

**A:** 영수증 상태에 따라 다릅니다.
- 깨끗한 영수증: 80~95% 정확도
- 흐릿하거나 구겨진 영수증: 50~70%
- 인식 후 사용자가 수정 가능

### Q4. 무료인가요?

**A:** 현재 초안 단계에서는 대부분 무료입니다.
- 무료: 모든 기본 기능 (영수증, 예산, 세금 계산, 내보내기)
- 향후 유료 예정: AI 분석, 은행 연동, 프리미엄 기능

### Q5. 은행 계좌 연동은 언제 되나요?

**A:** Phase 4에서 개발 예정입니다.
- 현재: 수동으로 계좌 정보 입력만 가능
- 향후: Plaid 또는 금융 API 연동으로 자동 거래 내역 불러오기
