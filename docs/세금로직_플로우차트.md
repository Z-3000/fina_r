## 1. 개인 세금 계산 전체 흐름

```mermaid
flowchart TD
    subgraph 입력["📥 입력 데이터"]
        A1[연간 총급여]
        A2[부양가족 수]
        A3[배우자 유무]
        A4[공제 항목들]
    end

    subgraph 소득공제["📉 소득공제 단계"]
        B1[근로소득공제<br/>연봉별 차등 공제율]
        B2[인적공제<br/>본인+배우자+부양가족]
        B3[특별공제<br/>4대보험, 신용카드 등]
    end

    subgraph 세금계산["💰 세금 계산"]
        C1[과세표준<br/>근로소득금액 - 공제]
        C2[산출세액<br/>세율표 적용]
        C3[세액공제<br/>의료비, 교육비 등]
        C4[결정세액<br/>최종 납부 세금]
    end

    subgraph 출력["📤 결과"]
        D1[소득세]
        D2[지방소득세<br/>소득세의 10%]
        D3[총 세액]
        D4[실효세율]
    end

    A1 --> B1
    B1 -->|"총급여 - 공제"| E1[근로소득금액]
    E1 --> C1
    A2 & A3 --> B2
    A4 --> B3
    B2 & B3 --> C1
    C1 -->|"세율표 적용"| C2
    C2 --> C3
    C3 -->|"산출세액 - 공제"| C4
    C4 --> D1
    D1 -->|"×10%"| D2
    D1 & D2 -->|"합계"| D3
    D3 --> D4

    style A1 fill:#e1f5fe
    style C4 fill:#fff9c4
    style D3 fill:#c8e6c9
```

## 3. 소득세율 구간

```mermaid
flowchart TB
    subgraph 과세표준["과세표준 구간 (2025년)"]
        A1["1,400만원 이하<br/>6%"]
        A2["1,400~5,000만원<br/>15%<br/>누진공제: 126만원"]
        A3["5,000~8,800만원<br/>24%<br/>누진공제: 576만원"]
        A4["8,800만~1.5억원<br/>35%<br/>누진공제: 1,544만원"]
        A5["1.5억~3억원<br/>38%<br/>누진공제: 1,994만원"]
        A6["3억~5억원<br/>40%<br/>누진공제: 2,594만원"]
        A7["5억~10억원<br/>42%<br/>누진공제: 3,594만원"]
        A8["10억원 초과<br/>45%<br/>누진공제: 6,594만원"]
    end

    A1 --> A2 --> A3 --> A4 --> A5 --> A6 --> A7 --> A8

    style A1 fill:#c8e6c9
    style A2 fill:#dcedc8
    style A3 fill:#fff9c4
    style A4 fill:#ffe0b2
    style A5 fill:#ffccbc
    style A6 fill:#ffcdd2
    style A7 fill:#f8bbd9
    style A8 fill:#e1bee7
```

### 세금 계산 공식

```
산출세액 = 과세표준 × 세율 - 누진공제액
```

**예시**: 과세표준 3,000만원
```
= 3,000만원 × 15% - 126만원
= 450만원 - 126만원
= 324만원
```

## 4. 신용카드 소득공제 로직

```mermaid
flowchart TD
    subgraph 입력데이터["📥 입력"]
        A1[연간 총급여]
        A2[신용카드 사용액]
        A3[체크카드 사용액]
        A4[현금영수증]
        A5[전통시장/대중교통]
        A6[문화비/체육시설]
    end

    subgraph 최저사용금액["🔢 최저사용금액 계산"]
        B1["총급여 × 25%<br/>(이 금액까지는 공제 없음)"]
    end

    subgraph 공제율적용["📊 결제수단별 공제율"]
        C1["신용카드: 15%"]
        C2["체크/현금: 30%"]
        C3["전통시장/교통: 40%"]
        C4["문화/체육: 30%"]
    end

    subgraph 한도적용["🎯 3중 한도"]
        D1["기본한도<br/>7천만↓:300만<br/>7천~1.2억:250만<br/>1.2억↑:200만"]
        D2["추가한도<br/>7천만↓:300만<br/>(시장+교통+문화+체육)<br/>7천만↑:200만<br/>(시장+교통만)"]
        D3["소비증가분<br/>전년대비 5%↑시<br/>10% 추가공제<br/>한도 100만원"]
    end

    subgraph 결과["✅ 최종 공제액"]
        E1[총 공제액]
    end

    A1 --> B1
    A2 & A3 & A4 & A5 & A6 --> |"총사용액 - 25%"| F1[초과 사용액]
    F1 --> C1 & C2 & C3 & C4
    C1 & C2 --> D1
    C3 & C4 --> D2
    F1 --> D3
    D1 & D2 & D3 -->|"각 한도 합산"| E1

    style B1 fill:#fff3e0
    style E1 fill:#c8e6c9
```

### 공제 순서 (중요!)

```mermaid
sequenceDiagram
    participant 최저 as 최저사용금액(25%)
    participant 신용 as 신용카드(15%)
    participant 체크 as 체크카드(30%)
    participant 시장 as 전통시장(40%)

    Note over 최저,시장: 공제율 낮은 순서로 25% 채움
    최저->>신용: 1. 신용카드로 25% 먼저 채움
    신용->>체크: 2. 남으면 체크카드
    체크->>시장: 3. 그 다음 전통시장
    Note over 시장: 남은 금액만 공제 대상!
```
