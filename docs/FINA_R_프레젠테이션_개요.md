# FINA_R 프레젠테이션 개요

> 개인/소상공인을 위한 스마트 세금 관리 앱
> 발표일: 2025-11-25 | 버전: v3.4

---

## 슬라이드 1: 타이틀

### FINA_R
**개인과 소상공인을 위한 스마트 세금 관리 플랫폼**

- 영수증부터 연말정산까지, 원스톱 세금 관리
- 2024/2025 최신 세법 반영

---

## 슬라이드 2: 문제 정의

### 왜 FINA_R이 필요한가?

| 기존 문제점 | 사용자 Pain Point |
|------------|------------------|
| 영수증 정리 | 종이 영수증 보관 귀찮음, 분실 위험 |
| 지출 파악 | 이번 달 얼마 썼는지 모름 |
| 예산 관리 | 과소비 인지 못함 |
| 세금 계산 | 복잡한 세율표, 공제 한도 이해 어려움 |
| 연말정산 | 환급 극대화 방법 모름 |

### 타겟 사용자
- **직장인**: 연말정산 환급 최적화
- **소상공인**: 부가세/종합소득세 관리
- **프리랜서**: 경비 처리 및 증빙 관리

## 슬라이드 3: 솔루션 개요

### FINA_R이 해결합니다

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   📷 영수증 OCR    →    📊 자동 분류    →    💰 예산 관리    │
│                                                             │
│   🧮 세금 계산     →    📋 연말정산     →    💡 절세 추천    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 핵심 가치
1. **자동화**: 영수증 사진 → 자동 인식 → 자동 분류
2. **시각화**: 지출/예산을 차트로 한눈에
3. **정확성**: 2024/2025 최신 세법 적용
4. **게이미피케이션**: 챌린지/배지로 절약 습관 형성

## 슬라이드 4: 주요 기능 (1/3)

### 영수증 관리 & OCR

| 기능 | 설명 |
|------|------|
| **OCR 인식** | Tesseract.js로 영수증 자동 인식 (한/영) |
| **자동 분류** | 가맹점명 기반 카테고리 자동 매칭 |
| **수동 입력** | 직접 입력도 지원 |

**인식 정보**: 날짜, 가맹점명, 금액, 결제수단

**카테고리**: 식비, 교통, 의료, 문화, 교육 등 15개

## 슬라이드 5: 주요 기능 (2/3)

### 예산 관리 & 대시보드

| 차트 | 용도 |
|------|------|
| **영역 차트** | 최근 6개월 지출 추이 |

### 세금 건강 점수 (Tax Health Score)
- 0~100점으로 세금 관리 상태 평가
- 4가지 세부 지표:
  - 세금 리스크
  - 증빙 완성도
  - 환급 가능성
  - 절세 여력

## 슬라이드 10: 세금 계산 로직

### 소득세 계산 흐름

```
총급여 → 근로소득공제 → 과세표준 → 세율 적용 → 산출세액
                                                    │
세액공제 ← 결정세액 ← 기납부세액 비교 ← 환급/추가납부
```

### 2024 소득세율표
| 과세표준 | 세율 | 누진공제 |
|----------|------|----------|
| 1,400만원 이하 | 6% | - |
| 5,000만원 이하 | 15% | 126만원 |
| 8,800만원 이하 | 24% | 576만원 |
| 1.5억원 이하 | 35% | 1,544만원 |
| 3억원 이하 | 38% | 1,994만원 |

### 구현된 세금 함수 (taxCalculator.js)
- `calculateIndividualTax()` - 근로소득세
- `calculateBusinessTax()` - 사업소득세/부가세
- `calculateCreditCardDeduction()` - 신용카드 소득공제
- `calculateDetailedTaxHealthScores()` - 세금 건강 점수
