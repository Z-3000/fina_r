## 3. MVP 시연 최적화 개선안

### 시연 시나리오 1: 직장인 연말정산 준비
```
1. 로그인 (test@naver.com)
2. 대시보드에서 세금 건강 점수 확인 (72점)
3. AI 인사이트 확인 → "연금저축 추가 납입 권장"
4. 공제 항목 추적 화면에서 현황 확인
5. 문서 공간에서 증빙서류 확인
6. 예상 환급액 계산 시연
```

### 시연 시나리오 2: 소상공인 세금 관리
```
1. 로그인 (test_00@naver.com)
2. 사업자 대시보드 확인 (월매출/경비/순이익)
3. 부가세 신고 준비 알림 확인
4. 매입/매출 세금계산서 관리
5. 종합소득세 예상 계산
6. 노란우산공제 추가 납입 권장 확인
```

### 시연 핵심 기능별 데이터 포인트

| 기능 | 직장인 데이터 | 소상공인 데이터 |
|------|--------------|----------------|
| 영수증 관리 | 월 60건+ (자동+수동) | 월 120건+ (사업경비) |
| 예산 관리 | 11개 카테고리 | 9개 카테고리 |
| 공제 추적 | 8개 항목 | 3개 항목 |
| AI 인사이트 | 4개 | 4개 |
| 문서 폴더 | 8개 | 7개 |
| 세금 계산 | 연말정산 | 부가세+종소세 |

### 날짜 설계 의도
- **2025.01.01 ~ 현재**: 세금 계산 용이 (1년 단위)
- **월별 데이터 자동 생성**: 시연 시점에 관계없이 적절한 데이터량
- **고정+변동 지출 혼합**: 현실적인 소비 패턴 재현
