## 연말정산이란?

**한 마디로**: 1년 동안 월급에서 미리 뗀 세금을 다시 계산해서, 더 냈으면 돌려받고 덜 냈으면 더 내는 것

### 비유로 이해하기

식당에서 밥을 먹을 때를 생각해 보세요:
- **월급날마다**: 일단 예상 금액(간이세액표)으로 세금을 떼어감
- **연말정산**: 1년치 영수증을 모아서 실제로 얼마 내야 하는지 정산
- **결과**: 더 낸 세금 → **환급** / 덜 낸 세금 → **추가 납부**

```
예시) 월급 400만원 직장인
├─ 매달 떼인 세금: 약 10만원 × 12개월 = 120만원
├─ 실제 내야 할 세금: 80만원 (공제 후 계산)
└─ 결과: 40만원 환급!
```

## 세금 계산의 큰 그림

### 5단계로 보는 세금 계산

```
1️⃣ 총급여 (연봉)
      ↓ (근로소득공제)
2️⃣ 근로소득금액
      ↓ (인적공제 + 특별공제)
3️⃣ 과세표준
      ↓ (세율 적용)
4️⃣ 산출세액
      ↓ (세액공제)
5️⃣ 결정세액 ← 이게 실제로 내야 할 세금!
```

### 각 단계 쉬운 설명

| 단계 | 이름 | 쉬운 설명 |
|------|------|----------|
| 1 | 총급여 | 1년간 받은 월급 총합 (세전) |
| 2 | 근로소득금액 | 총급여에서 기본적인 공제를 뺀 금액 |
| 3 | 과세표준 | "이 금액에 세금을 매깁니다" 라는 기준액 |
| 4 | 산출세액 | 세율을 적용해 계산한 세금 |
| 5 | 결정세액 | 세액공제까지 뺀 최종 세금 |

## 공제란 무엇인가요?

### 소득공제 vs 세액공제

두 가지는 **작동 방식이 다릅니다**:

#### 소득공제 = "세금 매기는 금액을 줄여줌"
```
예시) 신용카드 소득공제 100만원
├─ 과세표준이 100만원 줄어듦
├─ 세율 15% 적용 시
└─ 실제 줄어드는 세금: 15만원
```

#### 세액공제 = "세금 자체를 직접 깎아줌"
```
예시) 의료비 세액공제 100만원
└─ 내야 할 세금이 바로 100만원 줄어듦
```

> **결론**: 세액공제가 더 직접적! 같은 금액이면 세액공제가 유리

## 주요 공제 항목 쉬운 설명

### 1. 신용카드 소득공제 (가장 많이 사용)

**기본 원리**: 연봉의 25%를 넘게 쓰면, 초과분에 대해 공제

```
예시) 연봉 5,000만원, 카드 사용 2,000만원
├─ 최저사용금액: 5,000만원 × 25% = 1,250만원
├─ 공제 대상: 2,000만원 - 1,250만원 = 750만원
└─ 공제액: 750만원 × 15% = 약 112만원 (한도 300만원)
```

**결제수단별 공제율**:
| 결제수단 | 공제율 | 더 알기 쉽게 |
|----------|--------|-------------|
| 신용카드 | 15% | 가장 낮음 |
| 체크카드/현금영수증 | 30% | 신용카드의 2배! |
| 전통시장/대중교통 | 40% | 가장 높음 |

> **팁**: 연봉의 25%까지는 신용카드로, 그 이후는 체크카드로!

### 2. 연금저축/IRP (노후 대비 + 세금 절약)

**왜 좋은가요?**
- 노후 준비도 하고
- 세금도 줄어드는 1석 2조!

```
2025년 한도:
├─ 연금저축: 600만원
└─ IRP 포함: 900만원

세액공제율 (소득에 따라):
├─ 5,500만원 이하: 16.5%
├─ 5,500만원~1.2억: 15%
└─ 1.2억 초과: 13.2%
```

**실제 예시**:
```
연봉 5,000만원, 연금저축 400만원 납입 시
├─ 세액공제: 400만원 × 16.5% = 66만원
└─ 연말정산에서 66만원 돌려받음!
```

### 3. 월세 세액공제 (무주택 세입자 필수!)

**조건**:
- 무주택 세대주
- 총급여 8,000만원 이하
- 전용면적 85㎡ 이하 또는 기준시가 4억원 이하

**공제율**:
| 총급여 | 공제율 | 최대 공제액 |
|--------|--------|------------|
| 5,500만원 이하 | 17% | 170만원 |
| 5,500만원 초과 | 15% | 150만원 |

**실제 예시**:
```
연봉 4,000만원, 월세 80만원 (연 960만원)
├─ 공제 대상: 960만원 (한도 1,000만원 이내)
├─ 공제율: 17%
└─ 세액공제: 960만원 × 17% = 163.2만원 환급!
```

### 4. 의료비 세액공제

**기본 원리**: 총급여의 3%를 넘는 의료비만 공제

```
예시) 연봉 5,000만원, 의료비 300만원
├─ 기준: 5,000만원 × 3% = 150만원
├─ 공제 대상: 300만원 - 150만원 = 150만원
└─ 세액공제: 150만원 × 15% = 22.5만원
```

**특별 케이스**:
- 난임 시술비: 20% 공제 (더 높음!)
- 한도: 연 700만원

### 5. 교육비 세액공제

**한도 (1인당)**:
| 대상 | 한도 |
|------|------|
| 유아/초중고 | 300만원 |
| 대학생 | 900만원 |
| 본인 | 한도 없음 |

**공제율**: 15%

### 6. 자녀 세액공제

| 자녀 순서 | 공제액 |
|-----------|--------|
| 첫째 | 15만원 |
| 둘째 | 15만원 |
| 셋째부터 | 30만원씩 |

```
예시) 자녀 3명
├─ 첫째: 15만원
├─ 둘째: 15만원
├─ 셋째: 30만원
└─ 총 공제: 60만원
```

### 7. 4대보험 (자동 공제)

매달 월급에서 빠지는 4대보험료는 **전액 소득공제**!

| 보험 | 근로자 부담률 |
|------|---------------|
| 국민연금 | 4.5% |
| 건강보험 | 3.545% |
| 장기요양보험 | 건강보험의 12.95% |
| 고용보험 | 0.9% |

## 실제 예시로 보는 연말정산

### 사례: 김직장 씨 (연봉 5,000만원)

**기본 정보**:
- 연봉: 5,000만원
- 배우자: 있음
- 자녀: 1명 (초등학생)
- 신용카드 사용: 2,000만원
- 연금저축: 400만원
- 의료비: 200만원

**계산 과정**:

```
1️⃣ 총급여: 5,000만원

2️⃣ 근로소득공제:
   = 750만원 + (5,000만원 - 1,500만원) × 15%
   = 750만원 + 525만원 = 1,275만원

3️⃣ 근로소득금액:
   = 5,000만원 - 1,275만원 = 3,725만원

4️⃣ 인적공제:
   = 본인 150만원 + 배우자 150만원 + 자녀 150만원
   = 450만원

5️⃣ 신용카드 소득공제:
   = (2,000만원 - 1,250만원) × 15% = 약 112만원

6️⃣ 과세표준:
   = 3,725만원 - 450만원 - 112만원 - (4대보험 약 250만원)
   = 약 2,913만원

7️⃣ 산출세액:
   = 2,913만원 × 15% - 126만원 = 약 310만원

8️⃣ 세액공제:
   ├─ 연금저축: 400만원 × 16.5% = 66만원
   ├─ 의료비: (200만원 - 150만원) × 15% = 7.5만원
   ├─ 자녀: 15만원
   └─ 근로소득세액공제: 약 50만원
   = 총 138.5만원

9️⃣ 결정세액:
   = 310만원 - 138.5만원 = 171.5만원

🔟 지방소득세:
   = 171.5만원 × 10% = 17.15만원

💰 최종 세금: 약 189만원

📊 기납부세액 (월 원천징수 합계): 약 240만원

✅ 환급액: 240만원 - 189만원 = 약 51만원 환급!
```

## 소상공인 세금의 기초

> 사업을 시작하셨나요? 직장인과는 다른 세금 세계에 오신 걸 환영합니다!

### 소상공인이 내는 세금 종류

```
┌─────────────────────────────────────────────────────┐
│                소상공인의 세금                        │
├─────────────────────────────────────────────────────┤
│  📦 부가가치세 (VAT)                                 │
│     • 물건/서비스 팔 때 받은 부가세를 나라에 납부      │
│     • 1년에 2번 신고 (1월, 7월)                      │
│                                                     │
│  💰 종합소득세                                        │
│     • 1년간 번 돈에 대한 소득세                       │
│     • 1년에 1번 신고 (5월)                           │
│                                                     │
│  🏛️ 지방소득세                                       │
│     • 종합소득세의 10%                               │
│     • 종합소득세와 함께 신고                          │
└─────────────────────────────────────────────────────┘
```

### 직장인 vs 소상공인 세금 비교

| 구분 | 직장인 | 소상공인 |
|------|--------|----------|
| 세금 신고 | 회사가 대신 (연말정산) | **직접 신고** |
| 신고 시기 | 1~2월 | 1월, 5월, 7월 |
| 부가가치세 | 없음 | **있음** (핵심!) |
| 세금 종류 | 근로소득세 | 종합소득세 |
| 비용 공제 | 제한적 | **사업경비 인정** |

### 매출과 소득의 차이

많은 분들이 헷갈리는 부분입니다:

```
예시) 카페 사장님

매출 (총 들어온 돈):    1억원
  - 재료비:            3,000만원
  - 임대료:            1,200만원
  - 인건비:            2,000만원
  - 기타 경비:           800만원
─────────────────────────────
소득 (실제 이익):       3,000만원 ← 세금은 여기에!
```

> **핵심**: 세금은 **매출**이 아니라 **소득(이익)**에 부과됩니다!

## 간이과세자 vs 일반과세자

### 한눈에 보는 비교

| 구분 | 간이과세자 | 일반과세자 |
|------|-----------|-----------|
| **기준** | 연매출 1억 400만원 미만 | 연매출 1억 400만원 이상 |
| **부가세 계산** | 매출 × 업종별 부가가치율 × 10% | (매출 - 매입) × 10% |
| **세금계산서** | 발행 불가 (영수증만) | **발행 가능** |
| **매입세액 공제** | 0.5% (제한적) | **전액 공제** |
| **경감 혜택** | 50% 경감 (최대 100만원) | 없음 |
| **면세** | 4,800만원 미만: 납부 면제 | 없음 |

### 어떤 게 유리할까요?

```
🏪 간이과세자가 유리한 경우:
   • 매출 대비 매입(구입비)이 적은 업종
   • 서비스업, 소매업 등
   • 세금계산서 발행이 필요 없는 B2C 사업

🏢 일반과세자가 유리한 경우:
   • 매입(구입비)이 많은 업종
   • 도매업, 제조업 등
   • 법인 거래가 많아 세금계산서 필요
   • 초기 투자비용이 큰 경우 (환급 가능)
```

### 업종별 부가가치율 (2025년)

간이과세자의 부가세 계산에 사용됩니다:

| 업종 | 부가가치율 | 예시 |
|------|-----------|------|
| 소매업 | 15% | 편의점, 슈퍼마켓 |
| 음식점업 | 20% | 식당, 카페 |
| 숙박업 | 25% | 펜션, 모텔 |
| 건설업 | 30% | 인테리어, 수리 |
| 서비스업 | 30% | 미용실, 학원 |
| 운수업 | 30% | 택시, 화물 |
| 제조업 | 20% | 공장, 제작소 |
| 부동산임대 | 40% | 상가, 주택 임대 |

**계산 예시**:
```
음식점, 연매출 8,000만원

부가세 = 8,000만원 × 20%(부가가치율) × 10%
      = 160만원

경감 적용(50%) = 160만원 × 50% = 80만원

최종 납부: 80만원
```

### 부동산임대업 특별 기준

부동산임대업은 다른 업종과 기준이 다릅니다:

| 구분 | 일반 업종 | 부동산임대업 |
|------|----------|-------------|
| 간이과세 기준 | 1억 400만원 | **4,800만원** |
| 부가가치율 | 업종별 상이 | **40%** |

> ⚠️ 부동산임대업은 **4,800만원만 넘어도** 일반과세자!

## 소상공인 핵심 절세 방법

### 1. 노란우산공제 (★★★★★ 필수!)

**노란우산공제란?**
- 소상공인을 위한 **퇴직금 같은 제도**
- 매달 5~100만원 납입 가능
- 폐업/퇴직 시 목돈으로 돌려받음
- **납입액 전액 소득공제!**

```
┌────────────────────────────────────────────────┐
│     노란우산공제 소득공제 한도 (2025년 개정)    │
├────────────────────────────────────────────────┤
│  사업소득 4천만원 이하     →  연 600만원 한도   │
│  사업소득 4천만~1억원      →  연 400만원 한도   │
│  사업소득 1억원 초과       →  연 200만원 한도   │
└────────────────────────────────────────────────┘
```

**절세 효과 예시**:
```
연 사업소득: 5,000만원
노란우산 연납입: 400만원 (한도)

절세 효과:
├─ 소득공제: 400만원
```

## 자주 묻는 질문

### Q1. 신용카드를 많이 쓰면 무조건 좋은가요?

**A**: 아니요!
- 연봉의 25%까지는 공제 안 됨
- 25% 이후에도 한도(300만원)가 있음
- 카드값 결제는 해야 하니, **무리한 소비는 손해**

### Q2. 연금저축, 지금 넣어도 괜찮을까요?

**A**: 네! 장점이 많습니다:
- 세액공제로 당장 세금 절약
- 노후 대비
- 단, 55세 이전 해지 시 세금 부담 있음

### Q3. 맞벌이 부부는 누가 공제받는 게 유리해요?

**A**: 일반적으로 **소득이 높은 쪽**이 유리!
- 소득이 높을수록 세율이 높음
- 같은 공제액도 효과가 더 큼

### Q4. 증빙 서류를 안 챙기면 어떻게 되나요?

**A**: 공제를 못 받습니다!
- 영수증, 증빙 서류 꼭 보관
- 국세청 홈택스에서 대부분 조회 가능
- FINA가 영수증 OCR로 자동 정리해 드려요

### Q5. 연말정산 기간은 언제인가요?

**A**: 매년 1~2월
- 1월: 자료 조회 및 준비
- 2월: 회사에 제출
- 3월 월급: 환급/추가납부 반영

## 소상공인 자주 묻는 질문

### Q6. 간이과세자와 일반과세자, 어떤 게 나을까요?

**A**: 상황에 따라 다릅니다!

| 상황 | 추천 |
|------|------|
| 매출 대비 매입이 적다 (서비스업) | 간이과세자 유리 |
| 매입이 많다 (제조업, 도매업) | 일반과세자 유리 |
| 초기 설비투자가 크다 | 일반과세자 (환급 가능) |
| B2B 거래가 많다 | 일반과세자 (세금계산서 발행) |

### Q7. 노란우산공제, 꼭 해야 하나요?

**A**: **강력 추천!** 이유는:
- 납입금 **전액 소득공제** (세금 절약)
- **압류 금지** (사업 실패해도 보호)
- 폐업 시 **퇴직금처럼** 받음
- 연 복리 이자 적용

```
단, 주의사항:
• 중도해지 시 공제받은 세금 환수
• 연매출 3억(도소매 5억) 초과 시 가입 불가
```

### Q8. 부가세 신고는 언제, 어떻게 하나요?

**A**:

| 구분 | 신고·납부 기한 | 대상 기간 |
|------|---------------|----------|
| 1기 확정 | 7월 25일 | 1~6월 |
